# 📚 図書貸出管理システム (Library Lending System)

Spring Boot と Vanilla JavaScript で構築された、図書貸出・在庫管理システムです。
基本的な CRUD 機能に加え、実務を想定した厳格な貸出ルールと、動的な延滞判定ロジックを搭載しています。
「データの整合性」を最優先し、排他制御や多重バリデーションを含む堅牢な設計を重視して開発しました。

## 🌟 主な機能

### 👤 ユーザー機能
- **スマート貸出・返却システム**:
    - 貸出・返却アクションに連動した**在庫数のリアルタイム自動増減処理**。
- **厳格な貸出ガード機能**:
    - 1人最大 5 冊までの冊数制限、同一書籍の重複貸出禁止。
    - **延滞中の書籍がある場合、新規貸出をシステム側で完全にロック**。
- **動的警告表示**: ログイン時、延滞がある場合に独自デザインのモーダルで即座に通知。

### ⚙️ 管理者機能
- **延滞一括管理ダッシュボード**: 全ユーザーの貸出状況を横断的に照会し、延滞者を迅速に特定。
- **書籍・ユーザー管理 (CRUD)**:
    - **データ整合性保護 (削除ガード)**: 貸出中の書籍があるユーザーや、貸出されている書籍の削除を制限し、データの不整合を防止。

## 🛠 技術スタック

- **Backend**: Java 17 (LTS) / Spring Boot 3.x / Spring Data JPA
- **Frontend**: JavaScript (ES6+) / HTML5 / CSS3
- **Database**: PostgreSQL
- **Tools**: IntelliJ IDEA / Git / GitHub / Maven / JUnit 5 / AssertJ

## 💡 こだわった点・解決した課題

#### 1. 徹底したデータ入力チェックと多重バリデーション
システムの堅牢性を高めるため、フロントとバックの両層でバリデーションを実装しました。
- **バックエンド**: `Service` 層にて、必須項目の欠落や在庫数のマイナス入力、延滞の有無などを厳格にチェック。
- **フロントエンド**: モーダル経由の入力に対しリアルタイムなフィードバックを行うことで、不正リクエストの削減とユーザー体験の向上を両立しました。

#### 2. 階層型設計と GlobalExceptionHandler によるエラー処理の集約
「関心の分離」を徹底し、Controller、Service、Repository の役割を明確化しました。また、プロジェクト全体の例外処理を **GlobalExceptionHandler に集約**。コードの重複を排除し、一貫したレスポンスを返せる保守性の高い設計を実現しました。

#### 3. 悲観的ロックによる厳格な排他制御
同時実行による在庫不整合（Race Condition）を防ぐため、JPAの `@Lock(LockModeType.PESSIMISTIC_WRITE)` を採用。DBレベルで物理的に行をロックすることで、複数ユーザーの同時操作時でも、在庫のマイナス更新や不正な二重貸出を絶対に許さない堅牢な仕組みを構築しました。

#### 4. 独自のエラーハンドリングとUI/UXの連携
共通化されたエラーレスポンスをフロントエンドでキャッチし、**独自開発のモーダルメッセージ**に流し込む仕組みを構築。システム的なエラーをユーザーに分かりやすい言葉で伝える工夫を施しました。

#### 5. ユニットテストによる品質担保と境界値の検証
`JUnit 5` を用いて、特にバグが発生しやすい「貸出上限（5冊）」の境界値や、「延滞がある場合の貸出制限」や、不正入力に対する例外スローの検証を実施。仕様通りの動作を保証し、予期せぬバグの混入を未然に防ぐ品質管理を徹底しました。

#### 6. トラブルシューティング能力
開発中に直面したJPAエンティティと物理テーブルの命名不一致問題を、SQLログとEntity定義の詳細な照合により解決。根本原因を論理的に特定し、データ整合性を回復させた経験を通じて、デバッグ能力とデータ構造への深い理解を養いました。

## 🚀 セットアップ・実行方法

1. **リポジトリのクローン**
   ```bash
   git clone -b version-2-complete [https://github.com/risen1980tokyo-png/library_api.git](https://github.com/risen1980tokyo-png/library_api.git)

2. **データベース(PostgreSQL)の準備**

- PostgreSQLを起動し、データベース（例：library_db）を作成してください。

- src/main/resources/application.properties の接続情報（URL、ユーザー名、パスワード）をご自身の環境に合わせて設定してください。

3. **アプリケーションの起動**

- IntelliJ IDEA でプロジェクトを開き、Mavenのインポート完了後、LibraryApiApplication.java を実行します。

- 起動完了後、ブラウザで http://localhost:8080 にアクセスしてください。
